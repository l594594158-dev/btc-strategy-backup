## 修复一：K线数据获取不足导致ATR崩溃

### 问题
22:12~23:21 脚本崩溃，错误：`IndexError: index 13 is out of bounds for axis 0 with size 12`
根因：5分钟K线只有12根数据，ATR窗口需要14根，崩溃后死循环69分钟。

### 修复
- **calc()**: 数据不足14根时返回 None，主循环跳过该轮
- **get_data()**: 使用 `limit=200` 不含 `since`，稳定返回200根K线

```python
def get_data():
    k5m = binance.fetch_ohlcv(SYMBOL, timeframe='5m', limit=200)
    k1h = binance.fetch_ohlcv(SYMBOL, timeframe='1h', limit=200)
    k4h = binance.fetch_ohlcv(SYMBOL, timeframe='4h', limit=200)
    k1d = binance.fetch_ohlcv(SYMBOL, timeframe='1d', limit=200)
    return k5m, k1h, k4h, k1d

def calc(df):
    if len(df) < 14:
        return None
    # ...指标计算...
```

## 修复二：幽灵仓位标签问题

### 问题
bot自己开的仓，reason被误标记为"幽灵仓位同步"，而非实际开仓理由。

### 根因
补仓后 state 被整体替换时，reason 字段继承了旧数据中的幽灵标签。

### 修复
load_state() 增加 positions 数组循环转换：

```python
for pos in s['positions']:
    if pos.get('reason', '') in ('幽灵仓位同步', '', None):
        pos['reason'] = 'bot_recovered'
```

## 修复三：开仓间隔1.5%验证

### 规则
所有仓位之间必须保持1.5%间隔（不分方向）：

| 新仓方向 | 间隔要求 |
|---------|---------|
| 做多 | 新仓价 < 现有仓价 × 0.985 |
| 做空 | 新仓价 > 现有仓价 × 1.015 |

### 修复
开仓前验证所有现有持仓，不合格直接拒绝（不先下单再回撤）：

```python
# v2.12: 所有仓位之间必须保持1.5%间隔（不分方向）
exchange_pos = [p for p in binance.fetch_positions()
                if p.get('symbol') == SYMBOL and float(p.get('contracts', 0)) > 0]

if exchange_pos:
    for ep in exchange_pos:
        existing_entry = float(ep['entryPrice'])
        if direction == 'long':
            gap_pct = (existing_entry - candidate_price) / existing_entry * 100
        else:
            gap_pct = (candidate_price - existing_entry) / existing_entry * 100
        
        if gap_pct < 1.5:
            log(f"⛔ 开仓间隔不足({gap_pct:.2f}% < 1.5%)")
            return None
```
