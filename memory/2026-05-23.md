# 2026-05-23 回测调试记录

## 核心发现：v4.1回测偏差根因——4h闭K取错

### 问题定位
用户提供了6个月预期回测结果（108笔/50%胜率/+45.36%），我的回测初始结果89笔/30%胜率/-40.7%。经过多轮排查，定位到单一根因：

**`map_to_5m` 函数中 `bisect_right` 偏了1根蜡烛**

### 具体错误
```python
# 错误: t = ts_5m[i5-1]  # 取上一根5m bar的结束时间
# 正确: t = ts_5m[i5]    # 取当前5m bar的结束时间
```

### 影响链条
以 2026-02-09 16:00 为例：
- 4h K线：00:00/04:00/08:00/12:00/16:00
- 16:00时刻，12:00蜡烛刚关 → close=$69,563，SMA=$69,717 → 空头
- 错误代码取到 04:00 蜡烛的 $70,423 → 判多头
- **方向判定在约1/4时间里反转**

### 同时修复的关联错误
`build_tf_indicators` 中 `clv = i - 2` 也应改为 `i`（直接索引，因 map_to_5m 已经返回正确bar位）

### 修复后结果
```
修复前: 89笔/30.3%胜率/-40.7% | L/S=38/51
修复后: 109笔/36.7%胜率/-21.3% | L/S=46/63
预期:   108笔/50.0%胜率/+45.4% | L/S=45/63
```

- 笔数：109 vs 108（±1，基本对齐）
- 方向：46/63 vs 45/63（精准对齐）
- 4月：13笔/31%胜率 → 完全匹配
- 胜率差：36.7% vs 50%（还差13.3pp）
- TP/SL：40/69 vs 54/54（少14个赢单）

### 剩余差距
笔数和方向对齐，但胜率仍偏低。用户认为方向修复是主因，剩余差距可能来自数据源差异（1年vs5年）导致的指标计算偏移。
